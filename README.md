# ToDo IA

Aplicación de tareas desarrollada con React y preparada
para incorporar inteligencia artificial local en el navegador.

## Tecnología

- React 19 y JavaScript
- Vite
- CSS Modules
- i18next (español e inglés)
- localStorage
- Vitest, React Testing Library y Playwright
- GitHub Pages

## Funcionalidades actuales

- Añadir y eliminar tareas.
- Selección múltiple.
- Deshacer y rehacer.
- Persistencia local.
- Compartir tareas.
- Tres temas visuales.
- Español predeterminado.
- Sin tareas iniciales.

## Funcionalidades IA planificadas

1. Generación inteligente de tareas.
2. Traducción automática español/inglés.
3. Filtros semánticos multiselección.

Estas funcionalidades todavía no están implementadas.
