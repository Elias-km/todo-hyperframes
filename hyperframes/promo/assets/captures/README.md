# Capturas reales de la aplicación

Los PNG se generan en este directorio ejecutando, desde la raíz de `todo-hyperframes`:

```bash
npm run capture:promo
```

O bien `node hyperframes/capture/capture.mjs` si aún no está configurado el script npm.

No sustituir por mockups: la composición reproduce estas capturas de la interfaz React real, con datos de demostración controlados.
